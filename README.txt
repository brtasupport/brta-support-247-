# BRTA SUPPORT 24/7 — GitHub Pages PWA

## Upload these files to the root of your GitHub repository
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png
- .nojekyll

Then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

After deployment, open the HTTPS site in Chrome on Android and choose **Install app / Add to Home screen**.

IMPORTANT:
- Do not upload customer records, NID numbers, backups, passwords, or other private data to GitHub.
- GitHub stores the application files; customer records should remain in the app's local storage or in your private backup system.
